# 检验报告资料约定

## 身份

- 报告身份是 `(机构, 报告号)` 的组合；样品标识、规格和批次单独保存。
  同名不同规格的报告不会因为药名或报告号相同而合并。
- 页、原件、OCR 候选和通告映射都以报告身份为前缀，例如
  `lab-north/R-17/1`。补页沿用同一页标识的新版本；电子附件使用
  `<机构>/<报告号>/attachments/<文件名>`。
- 机构目录记录为 `catalog` 实体，保留目录地址、观察时间和条目原文。

## 原件与识别

- `page` 是目录或报告声明的页，`artifact` 是实际取得的字节。页图字节
  单独保存在 `entities.blob`，`byte_sha256` 只描述实际字节。
- 报告页上的 `image_sha256` 只是外部声明身份；与原件字节摘要不一致时
  记为 `页图摘要不符`，不覆盖原件。
- `ocr` 实体只存识别候选，`status` 恒为 `candidate`，不写入页或报告字段，
  也不能单独把通告映射升级为 `confirmed`。
- 来源正文不是 JSON 时按二进制原件解释；媒体类型和归属信息取自收据元数据。

## 版本关系

- 修订、补页与撤换附件都以新版本追加，旧版本不删除，并通过
  `entity_relations` 记录 `supersedes`、`fragment_of` 等关系。
- 同一实体同一版本的不同原文仍视为冲突，整笔事务回滚。

## 未决状态

- 缺页、原件未取得、样品标识缺失、批次未核实、映射仍为候选时，
  `publishable` 为假，原因写入 `reasons`。
- 报告号或机构无法核实的原件保存为 `unassigned/<字节摘要>`，只进入
  `candidates`，不归入任何报告或批次。
- 只有报告号在采集范围内唯一时，才允许旧式无机构页回退到无机构页标识。

## 续抓与追溯

- 冻结来源可按 `collection` 划分，每个集合有独立游标；某个机构重试不会
  消耗另一机构的响应。
- `trace` 按报告号（可加机构）列出每次取得的实体版本、来源 URL、收据摘要
  和版本关系；`blob`/`cat` 可按版本取回当次原件字节。
- 同一原文重复接收是幂等的，收据按字节摘要去重。
